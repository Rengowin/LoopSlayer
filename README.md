# LoopSlayer

This was my first unity experience.

A high-score game inspired by Loop Hero, developed as a university project for the Game Engines course at the HTW Berlin.

## About the Project

- top down view

## Gameplay

## Features

- scaring enemies with every loop
- upgrades
- score board (that stays even after the games is closed)
- C# data classes for enemies that the enemy types are based on
- creative use of the slider (at least what my profs said to me)
- additive scene loading (from game board to fight)

- 3 enemy typs
- upgrades

## Project History

The original project was developed during the Game Engines course from 20.09.2025 to 16.11.2025. In summer 2026, I revisited the project to improve UI scaling, fixed some bugs and got some quality featours like 1s pause after the combat is over, and prepare it for publication.
